# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and keep discussion focused on the work.
Harassment, personal attacks, and demeaning comments are not welcome here.

Report conduct issues by opening a private security advisory or contacting the
maintainers listed in the repository. Reports are handled confidentially.
